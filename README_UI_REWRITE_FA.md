# FELTROOM Reverb — بازنویسی رابط کاربری

این نسخه سورس رابط کاربری را برای نزدیک شدن به ماکت جدید بازنویسی می‌کند:
- نوار شش‌حالته Room / Hall / Plate / Chamber / Vintage / Ambient
- ناب‌های نورانی با نمایش عدد فشرده و واحد مناسب
- مرورگر Preset با دسته‌بندی، جست‌وجو، انتخاب سریع، قبلی/بعدی و Random
- دکمه‌های Save / Load / Settings در بالای پنجره
- حفظ اتصال ناب‌ها به پارامترهای AudioProcessorValueTreeState

## ساخت

این پروژه با CMake و JUCE 8.0.10 تعریف شده است. از پوشه پروژه اجرا کنید:

```bash
cmake -S . -B build
cmake --build build --config Release
```

خروجی VST3 در پوشه build ایجاد می‌شود (مسیر دقیق وابسته به سیستم‌عامل و generator است).

## نکته مهم

این تحویل شامل سورس است؛ در این محیط امکان تأیید کامپایل نهایی در DAW وجود نداشته است. بعد از ساخت، رابط را در DAW بررسی کنید. دکمه Save/Load برای فایل‌های XML پارامترهاست؛ فهرست User Presets در این نسخه دسته‌بندی نمایشی دارد و ذخیره دائمی نام‌های preset سفارشی هنوز اضافه نشده است.
